## 2. 当前与目标流程

### 2.1 普通截图当前流程

```text
热键 Ctrl+Shift+Q
  ↓
Application 记录原前台窗口，并捕获虚拟桌面背景
  ↓
SelectionOverlay：自由框选 / 窗口吸附 / 八点调区
  ↓ SelectionResult（物理像素 + SelectionAction）
Application::runCapturePipeline
  ↓ dispatch(CaptureRegion)
CaptureSession 保存 Image
  ↓
dispatch(Copy / Pin)，或打开保存对话框后保存 PNG
```

### 2.2 F3 接入后的目标流程

```text
SelectionResult.action == Edit
  ↓
dispatch(CaptureRegion)
  ↓
CaptureSession 中的原始 Image
  ↓
AnnotationOverlay + AnnotationDocument
  ↓
AnnotationRenderer 生成 rendered Image
  ↓
Application 将 rendered Image 写回 CaptureSession
  ↓
复用 Copy / Save / Pin
```

### 2.3 F6 当前流程

```text
Application 在 Overlay 前记录 owner_window
  ↓
用户选择固定物理像素矩形，点击“长截图”
  ↓
Overlay 不关闭：选区孔洞进入捕获透传，显示实时累计预览
  ↓
Application worker 调用 LongShotEngine
  ↓
Notepad profile 校验内容区和滚动目标
  ↓
CaptureEngine 重复截取同一矩形
  ↓
ImageStitcher 去重拼接
  ↓
暂停 / 继续 / 停止或自动到底
  ↓
UI 线程接收完成消息，成功图写入 CaptureSession 并自动复制
```

## 3. 已冻结的共享契约

### 3.1 SelectionResult

```cpp
enum class SelectionAction {
  None,
  Copy,
  Save,
  Edit,
  Pin,
  LongShot,
};

struct SelectionResult {
  bool cancelled{true};
  int x{0};
  int y{0};
  int width{0};
  int height{0};
  SelectionAction action{SelectionAction::None};
};
```

约定：

- `x/y/width/height` 离开 Overlay 时已经是物理屏幕像素；
- 支持虚拟桌面负坐标；
- `width/height > 0` 才是有效选区；
- F1/F2 不在结果中携带标注对象或窗口内部实现；
- `SelectionAction` 是 UI 完成意图，不等同于系统级 `ActionType`。

### 3.2 Image

- BGRA32；
- 行优先；
- `width * height` 个 `uint32_t` 像素；
- 不共享 HBITMAP / HDC 等平台句柄；
- Capture、Annotation、Pin、LongShot、Export 共用同一值类型。

### 3.3 CaptureSession

- 表达“当前最后一张有效结果”；
- 普通 Capture 成功后写入；
- F3 完成后用合成图覆盖当前结果；
- F6 只有成功完成后才覆盖；
- Copy / Save / Pin 消费当前结果；
- Pin 窗口自身的复制 / 保存必须消费各自持有的 Image，不能回读 Session。

### 3.4 共享文件

以下文件改动前需要集成负责人确认：

```text
include/qingying/action/image.hpp
include/qingying/action/types.hpp
include/qingying/app/capture_session.hpp
include/qingying/overlay/selection_overlay.hpp
include/qingying/longshot/longshot_engine.hpp
src/app/application.cpp
```

## 5. F3 标注开发边界

### 5.1 第一版范围

最小可交付先做：

- 矩形；
- 箭头；
- 画笔；
- 撤销；
- 合成结果回写；
- Copy / Save / Pin 回归。

随后增加：椭圆、文字、马赛克、重做和更完整样式。

### 5.2 建议文件

```text
include/qingying/annotate/annotation_types.hpp
include/qingying/annotate/annotation_document.hpp
include/qingying/annotate/annotation_engine.hpp
include/qingying/annotate/annotation_renderer.hpp
include/qingying/annotate/annotation_overlay.hpp
src/annotate/annotation_document.cpp
src/annotate/annotation_engine.cpp
src/annotate/annotation_renderer.cpp
src/annotate/annotation_overlay.cpp
tests/annotation_document_test.cpp
tests/annotation_engine_test.cpp
tests/annotation_renderer_test.cpp
tests/annotation_integration_test.cpp
```

建议把 `AnnotationOverlay` 放在 annotate target，而不是继续扩大 `selection_overlay.cpp`。

### 5.3 标注对象模型

```cpp
enum class AnnotationType {
  Rectangle,
  Ellipse,
  Arrow,
  Pen,
  Text,
  Mosaic,
};
```

至少需要：

- 几何：矩形 / 起终点 / 点序列；
- 样式：颜色、线宽、不透明度、字体大小、马赛克块大小；
- 唯一 ID 或稳定索引；
- 可复制或可移动的值语义，便于撤销 / 重做。

### 5.4 坐标契约

标注坐标永远相对于截图左上角：

```text
Image physical pixel (0,0) ─────────→ width
             │
             │ Annotation geometry
             ↓
           height
```

编辑器允许缩放显示，但必须只在视图层转换：

```text
屏幕输入坐标 ↔ AnnotationOverlay 视图坐标 ↔ Image 物理像素坐标
```

不得存储桌面绝对坐标，否则标注结果进入 Pin 或再次缩放时会产生偏移。

### 5.5 AnnotationEngine / Renderer 职责

```cpp
class AnnotationEngine {
 public:
  void clear();
  void add(Annotation annotation);
  bool undo();
  bool redo();
  Image render(const Image& source) const;
};
```

边界：

- 不处理 Win32 顶层消息循环；
- 不捕获屏幕；
- 不直接调用 `ActionDispatcher`；
- 不写剪贴板或文件；
- 鼠标移动期间只更新预览对象，不永久覆盖原始 Image；
- 最终提交时由 Renderer 生成新的 `Image`。

### 5.6 工具栏前置调整

当前 Selection 工具栏在 `selection_overlay.cpp` 内硬编码按钮 ID、创建、启用条件和 `WM_COMMAND` switch。F3 接线前建议先抽：

```text
ToolbarCommandDescriptor
  ├── command id
  ├── label
  ├── SelectionAction / local command
  ├── visible condition
  ├── enabled condition
  └── shortcut

SelectionToolbar
  ├── HWND 生命周期
  ├── 按描述创建按钮
  └── 只回传命令
```

注意：暂停、停止、撤销、工具选择属于 UI 本地命令；Copy、Save、Edit、Pin 属于完成意图。不要把所有按钮都塞进全局 `ActionType`。

### 5.7 F3 完成回调

建议：

```cpp
using AnnotationCallback =
    std::function<void(const Image& rendered_image)>;
```

取消编辑时应明确返回“取消”而不是空 Image。可改成结果结构：

```cpp
struct AnnotationResult {
  bool cancelled{true};
  Image image;
};
```

Application 只在 `cancelled == false && !image.empty()` 时覆盖 `CaptureSession`。

## 6. Application 集成负责人

Application / 后续 `CaptureWorkflow` 负责：

1. 消费 `SelectionResult`；
2. 为普通截图 dispatch `CaptureRegion`；
3. 从 Session 取得原始 Image；
4. 打开 AnnotationOverlay；
5. 接收合成后的 Image；
6. 写回 Session；
7. 再分发 Copy / Save / Pin；
8. 处理取消、空图、窗口关闭、保存失败和应用退出；
9. 保持 F6 worker 与 Overlay 生命周期正确。

集成负责人必须主要维护：

```text
src/app/application.cpp
include/qingying/app/application.hpp
include/qingying/app/capture_session.hpp
src/app/action_handlers.cpp
tests/*integration_test.cpp
```

标注开发者不能直接在 `Application::runCapturePipeline` 中边试边改；先提交稳定的标注接口和测试，再由集成负责人接线。

## 8. F6 长截图当前边界

### LongShotEngine 负责

- 校验 `LongShotRequest`；
- 通过应用 profile 找滚动目标和内容区；
- 始终截取请求中的固定物理矩形；
- 投递滚轮、等待内容稳定、抓取下一帧；
- 使用 `ImageStitcher` 去重拼接；
- 调用进度和继续回调；
- 到底、无新增、帧数 / 高度上限和用户停止；
- 失败清空输出并返回稳定错误。

### LongShotEngine 不负责

- 创建或操作 SelectionOverlay；
- 读取当前前台窗口来替换已记录 owner；
- 自动扩大为整个窗口 / 正文区；
- 修改 CaptureSession；
- Copy / Save / Edit / Pin；
- 管理应用顶层消息循环。

### 当前安全限制

```cpp
struct LongShotLimits {
  int max_frames{30};
  int max_output_height{30000};
};
```

另有显式到底、全帧重合 / 无新增、目标失效、选区非法和用户停止条件。
