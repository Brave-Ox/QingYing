## 2. 当前与目标流程

### 2.1 普通截图当前流程

```text
热键 Ctrl+Shift+Q
  ↓
Application 记录原前台窗口，并捕获虚拟桌面背景
  ↓
SelectionOverlay：自由框选 / 窗口吸附 / 八点调区
  ↓ SelectionResult（物理像素 + SelectionAction）
Application::runCapturePipeline
  ↓ dispatch(CaptureRegion)
CaptureSession 保存 Image
  ↓
dispatch(Copy / Pin)，或打开保存对话框后保存 PNG
```

### 2.2 F3 当前流程

```text
SelectionResult.action == Edit
  ↓
SelectionOverlay 关闭并只向 Application 返回 Edit 意图
  ↓
Application 使用 CaptureGuard + CaptureEngine 抓取编辑源图
  ↓
AnnotationOverlay + AnnotationEditorSession / AnnotationDocument
  ↓
AnnotationRenderer 生成 rendered Image
  ↓
SelectionResult.annotated_image 回到 Application
  ↓
Application 写回 CaptureSession 并自动 Copy
  ↓
composeCapturePreview 合成结果桌面预览
  ↓
SelectionOverlay(initial_selection) 恢复同一选区操作条
  ↓
Save / Pin / 再次 Edit
```

### 2.3 F6 当前流程

```text
Application 在 Overlay 前记录 owner_window
  ↓
用户选择固定物理像素矩形，点击“长截图”
  ↓
Overlay 不关闭：选区孔洞进入捕获透传，显示实时累计预览
  ↓
Application worker 调用 LongShotEngine
  ↓
Notepad profile 校验内容区和滚动目标
  ↓
CaptureEngine 重复截取同一矩形
  ↓
ImageStitcher 去重拼接
  ↓
暂停 / 继续 / 停止或自动到底
  ↓
UI 线程接收完成消息，成功图写入 CaptureSession 并自动复制
```

## 3. 已冻结的共享契约

### 3.1 SelectionResult

```cpp
enum class SelectionAction {
  None,
  Copy,
  Save,
  Edit,
  Pin,
  LongShot,
};

struct SelectionResult {
  bool cancelled{true};
  int x{0};
  int y{0};
  int width{0};
  int height{0};
  SelectionAction action{SelectionAction::None};
  Image annotated_image;  // Edit 确认后的 BGRA32 合成图，其它动作为空
};
```

约定：

- `x/y/width/height` 离开 Overlay 时已经是物理屏幕像素；
- 支持虚拟桌面负坐标；
- `width/height > 0` 才是有效选区；
- F1/F2 不在结果中携带标注对象或窗口内部实现；
- `SelectionAction` 是 UI 完成意图，不等同于系统级 `ActionType`。

### 3.2 Image

- BGRA32；
- 行优先；
- `width * height` 个 `uint32_t` 像素；
- 不共享 HBITMAP / HDC 等平台句柄；
- Capture、Annotation、Pin、LongShot、Export 共用同一值类型。

### 3.3 CaptureSession

- 表达“当前最后一张有效结果”；
- 普通 Capture 成功后写入；
- F3 完成后用合成图覆盖当前结果；
- F6 只有成功完成后才覆盖；
- Copy / Save / Pin 消费当前结果；
- Pin 窗口自身的复制 / 保存必须消费各自持有的 Image，不能回读 Session。

### 3.4 共享文件

以下文件改动前需要集成负责人确认：

### 5.3 标注对象模型

```cpp
enum class AnnotationType {
  Rectangle,
  Ellipse,
  Arrow,
  Pen,
  Text,
  Mosaic,
};
```

至少需要：

- 几何：矩形 / 起终点 / 点序列；
- 样式：颜色、线宽、不透明度、字体大小、马赛克块大小；
- 唯一 ID 或稳定索引；
- 可复制或可移动的值语义，便于撤销 / 重做。

### 5.4 坐标契约

标注坐标永远相对于截图左上角：

```text
Image physical pixel (0,0) ─────────→ width
             │
             │ Annotation geometry
             ↓
           height
```

编辑器允许缩放显示，但必须只在视图层转换：

```text
屏幕输入坐标 ↔ AnnotationOverlay 视图坐标 ↔ Image 物理像素坐标
```

不得存储桌面绝对坐标，否则标注结果进入 Pin 或再次缩放时会产生偏移。

### 5.5 AnnotationEngine / Renderer 职责

```cpp
class AnnotationEngine {
 public:
  bool add(const Annotation& annotation);
  bool replaceAt(std::size_t index, const Annotation& annotation);
  bool removeAt(std::size_t index);
  bool undo();
  bool redo();
  void clear();
  bool render(const Image& source, Image& out) const;
};
```

边界：

- 不处理 Win32 顶层消息循环；
- 不捕获屏幕；
- 不直接调用 `ActionDispatcher`；
- 不写剪贴板或文件；
- 鼠标移动期间只更新预览对象，不永久覆盖原始 Image；
- 最终提交时由 Renderer 生成新的 `Image`。

### 5.6 工具栏现状与后续调整

当前选区条和标注底栏继续共用 `qingying_ui` 的 `ModernToolbar`。选区条的 HWND、布局、Tooltip、绘制、命中测试与命令状态已抽入：

```text
SelectionToolbar
  ├── HWND 生命周期
  ├── SelectionToolbarItemModel
  ├── buildSelectionToolbarItems(OverlayPhase)
  └── 只回传 SelectionToolbarCommand
```

注意：暂停、停止、撤销、工具选择属于 UI 本地命令；Copy、Save、Edit、Pin 属于完成意图。不要把所有按钮都塞进全局 `ActionType`。

### 5.7 当前 F3 完成回调

```cpp
struct AnnotationFinishResult {
  bool cancelled{true};
  Image rendered_image;
};
```

`AnnotationOverlay::showInPlace` 通过 `AnnotationCallback` 回传该结果；取消时保持 `CaptureSession` 原图不变，确认时由 Application 填入 `SelectionResult.annotated_image`。

Application 只在 `cancelled == false && !rendered_image.empty()` 时覆盖 `CaptureSession`，随后自动分发 Copy，并恢复可 Save / Pin / Edit 的结果操作条。
结果操作条显示期间选区锁定；如需重新选区，应结束本轮并重新唤起截图，避免旧标注栅格与新矩形失配。

## 6. Application 集成负责人

Application / 后续 `CaptureWorkflow` 负责：

1. 消费 `SelectionResult`；
2. 为普通截图 dispatch `CaptureRegion`；
3. 维护普通截图的 Session 原始 Image；
4. 在 `SelectionOverlay` 返回 Edit 后用 CaptureGuard 产生编辑源图；
5. 由 `AnnotationOverlay` 产出 `AnnotationFinishResult`；
6. 接收 `SelectionResult.annotated_image` 并写回 Session；
7. 自动分发 Copy，并将标注结果合成进桌面预览，恢复 Save / Pin / Edit 操作条；
8. 处理取消、空图、窗口关闭、保存失败和应用退出；
9. 保持 F6 worker 与 Overlay 生命周期正确。

集成负责人必须主要维护：

```text

include/qingying/app/application.hpp
include/qingying/app/capture_session.hpp
src/app/action_handlers.cpp
tests/*integration_test.cpp
```

- 通过应用 profile 找滚动目标和内容区；
