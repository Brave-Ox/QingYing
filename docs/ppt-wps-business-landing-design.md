# WPS 业务落地结合单页设计

## 理解摘要

- 页面用于黑客松答辩，优先传达产品价值。
- 轻映定位为 AI 办公的本机桌面视觉入口。
- WPS 灵犀承接个人办公中的理解、总结与内容生成。
- WPS Comate 承接组织级 Skill、自动化编排和团队复用。
- 当前项目已有截图、长截图、标注、Pin 和受控 MCP 能力。
- 页面不宣称已经与灵犀或 Comate 完成正式产品接入。

## 假设与约束

- 轻映运行在用户 Windows 终端，本机完成图像采集与结果处理。
- 敏感画面由用户明确触发，外部智能体只能调用受控能力。
- AI 服务不可用时，轻映原有截图能力仍可独立工作。
- 不使用未经验证的效率百分比、用户规模或商业结果。

## 最终设计

采用“一个视觉入口、两级价值落地”的左右结构：

- 中心：轻映桌面视觉入口，展示截图、长截图、标注、Pin 与受控 MCP。
- 左侧：WPS 灵犀，强调跨应用取材、内容理解与文档/PPT生成。
- 右侧：WPS Comate，强调视觉 Skill、自动化任务与团队复用。
- 底部：从“复制粘贴”升级为“看见、理解、生成、协作”的价值闭环。

## 决策记录

1. 选择“双落地”方案，而不是单场景故事或纯技术架构，原因是更适合黑客松评委快速理解产品关系。
2. 轻映作为能力连接层，不替代灵犀或 Comate。
3. 灵犀突出个人效率，Comate 突出组织能力沉淀。
4. 只描述可落地结合方向，不把规划中的接入描述为已上线能力。
