## 诊断使用方式

在 PowerShell 中启用诊断并启动程序：

```powershell
$env:QINGYING_SMART_REGION_DIAGNOSTICS = '1'
.\build\bin\Release\qingying.exe
```

使用 DebugView 或调试器查看 `OutputDebugStringW` 输出。每次记录应至少包含：

- 最终来源和矩形；
- UIA 是否返回有效局部候选；
- MSAA 是否执行、是否命中及耗时；
- 已知内容区、视觉和最终选择耗时；
- 候选来源、语义、面积、Owner 覆盖率、置信度、评分和拒绝原因。

测试完成后清理当前 PowerShell 会话中的开关：

```powershell
Remove-Item Env:QINGYING_SMART_REGION_DIAGNOSTICS -ErrorAction SilentlyContinue
```
