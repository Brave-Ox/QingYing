## 当前已知实现边界

1. 全局候选最小尺寸为 16×16；视觉路径另有 24×20 的更严格限制。因此 12～24 px 控件不能简单依靠视觉规则放宽。
2. Chromium 已知内容定位只针对 `Chrome_RenderWidgetHostHWND` 等网页渲染窗口，标签栏、书签栏和地址栏不在此回退覆盖范围。
3. 每次悬停目前会先做快速检测，再为后台 UIA 请求重新做一次窗口定位；该重复工作列为任务 13。
4. 当前 UIA 异步结果以精确请求 ID 合并，快速移动时可能丢弃可用的近邻结果；该策略列为任务 15。

## 复测协议

1. 设置 `QINGYING_SMART_REGION_DIAGNOSTICS=1`，在每个目标元素悬停、停留、快速划过并点击一次。
2. 保存每次最终来源、矩形、候选评分/拒绝原因、异步 UIA 年龄、缓存命中、窗口身份和回退结果。
3. VSCode/PyCharm 任一目标从局部元素退化到 Client/Window 时，停止后续功能扩展并先处理回归。
4. 记录首帧、局部候选出现、候选切换、UIA、视觉和 Overlay 的 P50/P95，不能以主观流畅度替代测量。
