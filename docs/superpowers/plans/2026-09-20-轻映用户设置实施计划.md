# 轻映用户设置实施计划

> **面向执行代理：** 实施时必须使用 `subagent-driven-development`（推荐）或 `executing-plans`，逐任务执行并在每个任务后评审。所有步骤使用复选框跟踪。

**目标：** 为轻映增加中文原生设置窗口，使用户能够配置全局截图快捷键、截图过程快捷键、长截图上限、开机自启和本机 Agent 接口。

**架构：** 设置窗口只编辑草稿，由 `SettingsApplicationService` 协调校验、持久化、热键切换和系统设置副作用。快捷键与长截图限制使用结构化配置；长截图在每次任务启动时读取不可变限制快照，运行中的任务不受设置修改影响。

**技术栈：** C++17、Win32、Windows Registry、CMake、GoogleTest、现有 qingying app/workflow/longshot/ui 模块。

## 全局约束

- 只使用 Win32 原生控件和现有 GDI/GDI+ 能力，不增加 Qt、Electron、WebView 或第三方 UI 依赖。
- 头文件使用 `#pragma once`；类和结构体使用大驼峰，函数使用小驼峰，成员变量使用 `m_` 前缀。
- 使用 Allman 花括号风格；指针和引用符号紧贴类型。
- Win32 字符串使用 `std::wstring` 和 W 版本 API。
- HANDLE、HKEY、HFONT、HBRUSH 等资源必须使用 RAII 或明确的单一所有者。
- 不使用裸 `new/delete`，不手工传递裸指针所有权。
- 长截图最大帧数允许范围为 2～60，默认 30；最大输出高度允许范围为 3000～60000，默认 30000。
- 正在运行的长截图使用启动时快照，设置修改只影响下一次任务。
- 所有用户可见文案使用中文。
- 本计划不包含 `git add`、`git commit`、`git push`、`git reset`、`git rebase` 或 `git stash`；Git 操作由用户另行决定。
